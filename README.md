A simple, lightweight, and interactive web tool that helps users track character counts in real-time and prevents them from exceeding defined text limits. Perfect for social media posts, SEO meta descriptions, or SMS drafting.

## ✨ Features

- **Real-time Counting**: Instant character and word count as you type.
- **Visual Progress Bar**: A dynamic bar that changes color as you approach the limit.
- **Warning System**: Highlighting text or changing UI colors when close to the limit.
- **Clean UI**: Minimalist and responsive design built for all screen sizes.
- **Copy to Clipboard**: Easily copy your final text with one click.

---

## 🛠️ Built With

- **HTML5**: For the semantic structure.
- **CSS3**: Custom styling with Flexbox/Grid.
- **JavaScript (ES6+)**: Logic for real-time tracking and event handling.

## ⚙️ Installation & Usage

1. **Clone the repository:**
   ```bash
   git clone https://github.com/mehedi-hasan2006/Text-limit-checker.git
   ```

2. **Navigate to the directory:**
    ```bash
    cd Text-limit-checker
    ```
3. **Open the project:** <br>
Simply open `index.html` in your favorite browser.
